# ABC Bank Customer Analytics – Python

## Project Overview
This project analyzes bank customer data using Python to understand customer behavior, financial activity, digital banking usage, complaints, satisfaction and customer churn.

The objective is to identify patterns that can help the bank improve customer retention and make better data-driven business decisions.

## Business Problem
ABC Bank wants to understand why customers leave the bank and identify customer segments with higher churn risk.

The analysis focuses on customer demographics, account balances, transactions, loans, complaints, satisfaction and digital banking behavior.
